Make it work on iPhone

Home Screen

A downloaded HTML file is not automatically a real installed web app. To get an app-style Home Screen icon, this page must be hosted at an HTTPS website first.

  1. Host the file on a static HTTPS service (for example, GitHub Pages or Netlify).
  2. Open the published HTTPS link in Safari on your iPhone.
  3. Tap Share → Add to Home Screen → Add.

Reliable reminders right now

  1. Open the iPhone Clock app and add a 5:15 AM alarm labelled “LOCKED IN — run & routine.”
  2. In Reminders, create “Pack school bag, food and gym clothes” for 8:30 PM daily.
  3. Add a 7:15 PM reminder on Monday, Tuesday, Thursday and Friday: “Pre-gym snack, then full-body workout.”
Important: iOS web push notifications require a properly hosted, installed web app and push-notification support. This standalone file does not have a server, so its reminder buttons cannot notify you when it is fully closed.

Discipline standards

• Pack school bag, gym clothes and food the night before.
• Eat regular meals and drink water through the day.
• Use controlled reps; stop for sharp pain, dizziness or unusual exhaustion.
• Don't double workouts to make up for a missed day.
• Protect sleep: teens generally need 8–10 hours; adults generally need 7–9.
• Keep runs easy while building the habit; walk/jog if you're new to running.
• No max-out attempts or training to failure on every set.
